# V20.2.5 — audit hardening

## Fixed
- Vercel build failure caused by `PortalStudioOffer` being absent from manual upload: the account page no longer imports that component.
- Prepaid-hour Stripe webhook fulfilment is retry-safe: credit is inserted idempotently before payment is finalized locally.
- Refunds use a deterministic Stripe idempotency key and an atomic Supabase refund application function.
- Current SMS notification types are accepted by `notification_log`.
- Request-a-call / website enquiries now email active owners.
- Added a prebuild missing-relative-import check.

## Required before deploy
Run `supabase/v20-2-5-audit-hardening.sql` once in Supabase SQL Editor.

## Still being audited
Canonical fresh-database rebuild, rate limiting, timezone consolidation, automated E2E suite, dependency lockfile, security headers and outbox/retry architecture remain separate audit work. They are not falsely marked complete by this release.
