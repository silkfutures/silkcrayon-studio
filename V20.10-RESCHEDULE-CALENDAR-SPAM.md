# V20.10 — Owner reschedule, Apple Calendar, enquiry spam protection

## Owner reschedule
- Open an upcoming session in Studio OS.
- Owners now see **Reschedule session**.
- Pick a new date and an actually available slot; the current booking is excluded from the clash check.
- Keeps payment state and engineer assignment on the same booking.
- Clears any stale customer change request, writes an audit event, emails/texts the customer, and emails the assigned engineer.

## Apple Calendar
- `/admin/calendar` now includes **Subscribe in Apple Calendar**.
- The private subscription feed reflects pending/confirmed Studio OS bookings and uses stable booking UIDs, so moved sessions update on feed refresh.
- Individual session pages also include **Add to calendar** for a one-off `.ics` file.
- Feed token is derived from `CALENDAR_FEED_TOKEN` when set; otherwise from the existing server-side Supabase secret. The underlying secret itself is never exposed.
- Recommended: add a long random `CALENDAR_FEED_TOKEN` in Vercel, then redeploy. Changing it invalidates the old subscription URL.

## Enquiry spam protection
- Honeypot field.
- Minimum realistic form completion time.
- Layered server-side bot scoring.
- Per-IP + per-email rate limits.
- Spam receives a generic success response but is not written to leads/CRM and does not email the owner.
- Enquiries admin now has per-item **Delete spam** and a conservative **Delete obvious spam** cleanup action.

## Database
No new Supabase migration required.
