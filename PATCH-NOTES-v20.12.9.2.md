# Silkcrayon OS v20.12.9.2 — persistent back navigation

Apply this incremental patch after v20.12.9.1.

Every OS page below the main overview now has a persistent Back button. It returns to the actual previous OS screen when history is available. Directly opened detail pages fall back to their parent section, while top-level owner tools fall back to More.

The public website and customer portal are unchanged. No Supabase migration is required.
