# V20.5 — Promotions architecture

- Added owner-controlled `promotions` table and Studio OS → More → Promotions.
- Relaunch 2h/£100 is now a Vocal Recording duration promotion, not a separate booking service card.
- Booking UI receives live promotions server-side and displays a tactile starburst sticker plus offer duration treatment.
- `/api/checkout` re-resolves the live promotion server-side, enforces per-customer usage, records list/discount/promotion audit data, and prevents stacking with the 5% email reward.
- Homepage promotion moved directly below the opening proof strip, before the long experience/services content.
- Homepage CTA now opens Vocal Recording with 2 hours preselected.
- Existing prepaid-hour, gift, banked-hour, Stripe webhook, availability and customer-account systems are otherwise untouched.
- Run `supabase/v20-5-promotions.sql` before deploying this patch.
