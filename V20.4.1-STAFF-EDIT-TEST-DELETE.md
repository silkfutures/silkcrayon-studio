# V20.4.1 — Staff editing + refunded test deletion

## Staff
- Admin → Staff now exposes editable staff profile cards.
- Edit display name, customer-facing engineer name, email, phone and role.
- Updating staff email also updates the Supabase Auth login email.
- Existing Auth email is shown when the profile email field is blank.
- New staff creation stores email and phone on the staff profile.

## Test customers
- Delete-test-customer now reconciles refund audit rows as before.
- If local refund state is stale, it also asks Stripe for the PaymentIntent/latest Charge and verifies `amount_refunded`.
- Fully refunded 30p/£1 test bookings are normalized to `payment_status=refunded` before the existing safe-delete RPC runs.
- Real bookings over £1 remain protected.

## Required SQL
Run `supabase/v20-4-1-staff-contact-fields.sql` once before deploying this build.
