# V9 — Customer Journey

1. Run `supabase/v9-customer-journey.sql`.
2. Add `STUDIO_ADDRESS`, `STUDIO_MAP_URL`, `GOOGLE_REVIEW_URL` to Vercel.
3. Optional: create a Stripe promotion code, then add the same code as `REBOOK_DISCOUNT_CODE`.
4. Redeploy.

Includes redesigned confirmation screen, first-time vs returning confirmation emails, richer owner notification, redesigned reminder, immediate post-session follow-up, Google review CTA, and rebooking offer. Review and discount are deliberately separate.
