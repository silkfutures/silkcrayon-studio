# Silkcrayon — Vercel first draft

Static HTML/CSS/JS first draft using the supplied Silkcrayon photography.

## Run locally
Open `index.html` directly, or run any static file server.

## Deploy to Vercel
1. Create a GitHub repository.
2. Upload everything in this folder to the repository root.
3. In Vercel, import the repository.
4. Framework preset: **Other**.
5. Build command: leave blank.
6. Output directory: leave blank/root.
7. Deploy.

## Before launch
- Replace the Spotify placeholder in `index.html` with the real Spotify playlist iframe.
- Change the “Open booking system” href to the exact Wix Bookings URL.
- Confirm pricing/copy.
- Add analytics and SEO/social metadata if desired.
