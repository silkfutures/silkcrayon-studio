# V20.11 — Universal pricing + reschedule hotfix

Studio OS → Settings is now the central commercial control for hourly studio price, full-day price, the 2-hour relaunch offer, and Studio Finish price/turnaround/revisions.

This version removes the old £60/hour logic from the individual-session upsell, makes booking duration prices and prepaid/gift-hour displays use the live OS settings, updates key website/customer price displays, makes session follow-up and Studio Finish purchase emails use current settings, fixes the prepaid-hours price scale, and includes the owner-reschedule schema compatibility fix.

## Deploy
1. Upload the patch contents preserving exact paths.
2. Run `supabase/v20-11-universal-pricing-reschedule-hotfix.sql` once.
3. Redeploy Vercel.
4. Open Studio OS → Settings and press **Save all pricing** once.
5. Test a 1-hour booking, individual-session upsell, Studio Finish checkout, manual booking, relaunch offer, and owner reschedule.
