# Silkcrayon Studio OS V20.4.4 — Manual booking hours fix

Includes all V20.4.3 changes.

## DM / phone booking duration
- Fixes the Hours field jumping to 8 when a new number is typed into the existing `1`.
- The field now preserves the raw value while the user is typing instead of clamping every keystroke.
- Duration is validated between 0.5 and 8 hours.
- On blur, the value is normalised to the nearest 0.5 hour and capped to the valid range.
- Session end time and £60/hour value still update automatically.
- Backend validation remains unchanged and still enforces 0.5–8 hours.

## SQL
If V20.4.3 has not been deployed yet, run:
`supabase/v20-4-3-staff-arrival-fields.sql`

Do not run the older V20.4.1 staff SQL separately if you are starting from the pre-V20.4.1 database.
