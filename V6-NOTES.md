# Silkcrayon Studio OS V6

V6 focuses on role separation and the engineer experience. No database migration is required beyond the V5 schema.

Engineer flow:
- `/admin/engineer` — clean Today dashboard
- `/admin/engineer/session/[booking-id]` — guided live session view
- `/admin/artists` — mobile artist search/registration
- `/admin/payments` — guided payment/package flow
- `/admin/sessions` — simplified 3-step engineer report

Owner flow remains at `/admin` with the full operational dashboard.
