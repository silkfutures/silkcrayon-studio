# V18.1 — booking UX, portal onboarding & email delivery polish

- Mobile Studio OS tab bar is anchored flush to the bottom of the iOS viewport.
- Booking checkout bar is completely hidden until:
  - an available time is selected
  - customer name is entered
  - a valid email is entered
  - No Harmful Music Policy is accepted
- Booking confirmation now contains a secure one-use My Studio login link valid for 7 days.
- First-booking confirmation has expanded Silkcrayon onboarding + No Harmful Music Policy context.
- Transactional emails now send both HTML and plain-text bodies.
- Optional `EMAIL_REPLY_TO` supported.

Email inbox placement cannot be guaranteed by application code. Once silkcrayon.com is the live domain, verify the exact sending domain in Resend and complete SPF/DKIM + DMARC.
