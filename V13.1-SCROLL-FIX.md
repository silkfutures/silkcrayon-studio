# V13.1 — Mobile scroll/navigation hotfix

The mobile menu was previously always mounted as a full-screen fixed element and hidden using a transform.
On iOS Safari that fixed/transformed descendant could leak back into the viewport during scroll/repaint, which caused the large
`Services / The space / Listen / My Studio` links to appear over normal page sections.

V13.1:
- removes the mobile menu from the DOM entirely while closed
- locks body/html scrolling only while the menu is open
- uses `100dvh`/`100svh` safely for the open menu
- disables the old transform-based off-canvas hiding
- prevents horizontal overflow on the marketing site
- hides the fixed Book bar while the nav menu is open

No SQL or new environment variables required.
