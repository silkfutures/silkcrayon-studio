# V20.2 FINAL — Contacts + Email + Twilio SMS + preferred engineer

Use this build instead of V20 or V20.1 if neither has been deployed.

## One SQL file
Run:
`supabase/v20-2-FINAL-LAUNCH.sql`

It includes:
1. V20 leads/enquiries
2. the supplied Wix contact import + marketing CRM
3. SMS consent + preferred-engineer fields

## Contacts
- full Wix contact database imported
- select one/many/all filtered contacts
- Email selected
- Text selected
- separate email and SMS permission statuses
- hard skip for unknown/unsubscribed recipients in promotional sends
- manual status changes require a warning/confirmation in the UI

## Twilio
Vercel variables:
- TWILIO_ACCOUNT_SID
- TWILIO_AUTH_TOKEN
- TWILIO_MESSAGING_SERVICE_SID (recommended)
- TWILIO_FROM_NUMBER (fallback if not using a Messaging Service)
- TWILIO_VALIDATE_WEBHOOKS=true

Booking form now has separate consent for:
- booking/service texts
- email marketing
- SMS marketing

When booking/service texts are enabled:
- SMS confirmation after paid booking
- SMS next-day reminder

For marketing SMS, texts append `Reply STOP to opt out.`

Recommended Twilio setup:
- create a Messaging Service
- enable Advanced Opt-Out
- set incoming-message webhook to:
  `https://www.silkcrayon.com/api/twilio/inbound`
This keeps STOP/START status synced back into Silkcrayon OS.

## Preferred engineer
- optional Preferred Engineer field during booking
- preference stored on the customer profile and the individual booking
- owner assignment screen flags the preference
- the artist can still choose “No preference”
- preference does NOT automatically assign the engineer; owner remains in control

## Engineer assignment email
Assignment email now includes:
- artist
- service
- date/time
- studio address
- preferred-engineer note when relevant
- VIEW SESSION button
- ADD TO CALENDAR button

The calendar button opens a pre-filled Google Calendar event.

## Marketing launch
The existing Resend Marketing Centre remains for normal email broadcasts.
Contacts also supports manual/selective email and SMS sends.
