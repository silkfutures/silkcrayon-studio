# Silkcrayon Studio OS V20.4.7

Includes all V20.4.6 changes.

## UK date formatting
Customer-facing and Studio OS date displays now use readable UK wording such as:
`Wednesday 19th August`
instead of `2026-08-19`.

A shared `lib/dates.js` formatter is used across the booking confirmation, manual booking flow, owner overview, session reports, artist/customer history, change requests and activity timestamps.

Database/API date values remain ISO (`YYYY-MM-DD`) internally, which is correct and should not be changed.

## Public mobile menu
The hamburger menu has been reduced to:
- Services
- The Space
- Young Creators
- Getting Here
- My Studio
- Book a session

Buy Hours, Gift Studio Time, Listen and Instagram remain reachable from the site itself but no longer overload the primary mobile menu.

## Visual calendar
New route: `/admin/calendar`
- Month-by-month visual schedule
- Bookings show time, artist and service
- Owner view also shows studio blockouts
- Engineer view only shows that engineer's assigned bookings
- Linked from Studio Overview, Sessions, Engineer quick actions and More

This is the first calendar layer. It deliberately does not yet connect to personal Google/Apple calendars. The next external-integration step should be either authenticated Google Calendar sync or a secure subscription feed once the in-app schedule has been used and validated.

## App feel/performance
- Adds route-level loading feedback so taps feel acknowledged while server data loads.
- Removes expensive backdrop blur from the fixed mobile bottom navigation.
- Adds mobile touch-action optimisations.
- Bumps the PWA service-worker/cache version to V20.4.7 so installed apps do not stay pinned to older static assets.
- Keeps navigation network-fresh.

## SQL
Run the existing V20.4.5 migration before/with deployment if it has not already been run:
`supabase/v20-4-5-manual-booking-notification-types.sql`
No additional SQL is required for the V20.4.7 calendar/date/performance changes.
